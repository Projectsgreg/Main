## 🚀 Quick Start

### 1. Image Setup
- Upload images to respective folders:
  - `media/greg/`: greg-1.jpg to greg-20.jpg
  - `media/wellness/`: wellness-1.jpg to wellness-10.jpg
  - `media/business/`: business-1.jpg to business-10.jpg
  - `media/testimonials/`: testimonial-1.jpg to testimonial-5.jpg
  - `media/logos/`: favicon.ico and brand logos

### 2. Configuration
Update `config.json` with your actual:
- Contact email addresses
- YouTube API key
- Formspree endpoints
- Calendly username

### 3. Deployment
1. Enable GitHub Pages in repository settings
2. Configure DNS at Porkbun:
   - 4 A records pointing to GitHub Pages IPs
   - 1 CNAME record for www subdomain

## 🛠️ Technology Stack
- **Hosting:** GitHub Pages (Static)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Integrations:** YouTube API, Calendly, Formspree
- **Styling:** Custom CSS with CSS Variables
- **Images:** Dynamic shuffling system
